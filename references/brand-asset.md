# 品牌资产协议（brand-assets）

只要内容里出现**能被认出的品牌 / 产品**，读者就会拿真实资产对照。抽象 mock 会一眼假。

## 触发条件

1. 为某个品牌做物料（官方账号、品牌合作）。
2. 内容里出现任何真实品牌或产品：评测、对比、榜单、推荐、案例。

## 五步

1. **问**：有没有官方 logo、品牌色、产品图、UI 截图、VI 规范。
2. **搜**：官网 / 官方媒体包 / 应用商店截图 / GitHub 仓库。
3. **下载**：原始分辨率，不要截图二次压缩。
4. **核验**：logo 版本是否正确、产品界面是否当前版本、有没有过时元素。
5. **固化**：写进项目根目录的 `brand-spec.md`，设计统一引用。

## brand-spec.md 模板

```md
# 品牌资产 · <品牌名>

- 品牌名 / 英文名：
- Logo 文件：assets/brand/logo.svg（主）/ logo-dark.svg（深底）
- 品牌色：主色 #______ / 辅色 #______（来源：官网）
- 字体：标题 ______ / 正文 ______
- 产品截图：assets/brand/ui-01.png（版本 v1.2，2026-11-16）
- 使用限制：logo 最小尺寸 / 留白 / 不可改色
```

## 没有官方资产时

- 用**诚实占位**：灰底矩形 + 「产品截图位 1200×800」/「示意，非官方素材」。
- 不要手绘品牌 logo，不要伪造 UI。
- 正文里注明「示意图」。
