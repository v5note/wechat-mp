# 打磨环（polish-loop）

第一版只是草稿。**写完不算完，看过自己的截图再改才算。**

## 流程

1. 生成预览：
   ```bash
   node scripts/build.mjs --spec <spec> --out <dir>   # 会自动跑 check.mjs
   node scripts/preview.mjs --demo examples/demo      # 生成总览图
   ```
2. **逐张打开原尺寸截图/总览图**，不要只看缩略图。
3. 写下**最伤的三处**（文字溢出 / 断行难看 / 主体越安全区 / 图注重复 / 层级不清 / 信息太挤 / 配色脏 / 假数据）。
4. 改。
5. 再生成、再看，直到认真看完找不出值得改的三处。**正式版至少 2 轮。**

## 自检记录：polish-log.md

每轮写下来，放在项目根目录：

```md
# 打磨记录 · <项目名>

## 第 1 轮（2026-11-16）
- 最伤①：卡片标题第二行贴边 → 缩小字号/加安全区
- 最伤②：图2 图注与图片内图注重复 → 删图片内图注
- 最伤③：配图2 与上下文无关 → 换成流程图
- 修改：...

## 第 2 轮
- 三处已改，无新问题。
```

## 看什么（八个问题）

1. 第一眼 3 秒能懂这一张/这一屏在说什么吗？
2. 标题有没有断在难看的词上、有没有贴边？
3. 主体是否越安全区（四周 ≥64px）？
4. 图注是否重复、编号是否连续？
5. 每张卡是否只讲一件事、只有一个强调色？
6. 配色是否脏、对比是否够（正文 ≥4.5:1）？
7. 有没有编造的数据 / 评价 / logo？
8. 和另一个版本相比，是否只是换色？结构有没有真的不同？
