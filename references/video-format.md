# 视频号规范（video-format · 可选产出）

> 视频号是**可选增量产出**：默认交付仍有贴图 + 文章。用户要「配个视频」「发视频号」「口播」时才做。
> 不替代文章；视频脚本从同一份事实与卖点里裁出来，一条视频只讲一个点。
>
> **两种产出档位**：**三件套**（默认，封面 + 口播稿 + 分镜，给你去录）｜**可上传 mp4**（加 `--render-video`）。
> mp4 由 `scripts/video-render.mjs` 渲染：卡片作画面、字幕烧录、可选 TTS 旁白（macOS `say`，**机器音**，正式发布建议照同一份口播稿真人重录）。需要本机 `ffmpeg`。

## 1. 规格

| 项 | 值 |
|---|---|
| 画幅 | 竖版 **1080×1920（9:16）**；封面同尺寸 `video/cover.png` |
| 安全区 | 顶部 220px（状态栏）/ 底部 360px（评论与操作）不放主体 |
| 时长 | 口播 30–60s；图文轮播 15–40s；屏幕解说 45–90s |
| 字幕 | 单屏 ≤12 字；关键词放大或变色；与口播同步 |
| 节奏 | 前 3 秒必须出钩子（反常识/结果/痛点），每 3–5s 一个信息点 |
| 封面 | 大标题 2 行 + 一个视觉锚点；与首帧一致，不做标题党落差 |

## 2. 三种形式

### 2.1 口播干货（oral）
- 画面：真人或数字人口播 + 大字幕 + 关键画面/截图 B-roll。
- 结构：钩子（3s）→ 结论 → 2–3 个论据（各 10–15s）→ 边界 → CTA。
- 交付：口播稿（逐句）、分镜表、竖版封面。

### 2.2 图文轮播（carousel）
- 画面：6–9 张竖版卡片（可直接复用贴图卡），按节奏切换，可配轻音乐。
- 结构：封面 → 每张一个要点 → 结尾 CTA。
- 交付：卡片序列 + 转场说明 + 封面。

### 2.3 屏幕解说（screencast）
- 画面：录屏 + 旁白 + 局部放大/箭头标注。
- 结构：问题 → 操作演示（分步）→ 结果 → 提醒。
- 交付：录屏脚本（每步说什么、点哪里）、标注点、封面。

## 4. 产出结构

```
<case>/video/
  cover.png      # 1080×1920 竖版封面
  口播稿.md       # 标题 / 钩子 / 口播全文 / 字幕要点 / 话题 / CTA
  分镜.md         # 镜号 | 时间 | 画面 | 口播 | 字幕 | 素材 + 制作提示
  video.mp4      #（--render-video）1080×1920 / 30fps / H.264 + AAC，可直接上传视频号
  字幕.ass        #（--render-video）烧录字幕源，单屏 ≤12 字
  渲染说明.md     #（--render-video）时长、音频来源、分镜时间轴、重渲染命令
```

渲染命令：

```bash
# 连同整套一起出（含视频）
node scripts/build.mjs --spec <spec.json> --out <版本目录> --render-video
# 只出图文轮播、不配 TTS
node scripts/video-render.mjs --spec <spec.json> --out <版本目录> --no-tts
```

## 5. 自检

- [ ] 封面 1080×1920，主体不压顶/底安全区。
- [ ] 分镜 ≥4 镜，前 3 秒有钩子。
- [ ] 单屏字幕 ≤12 字，与口播同步。
- [ ] 一条视频只讲一个点；结尾一个 CTA。
- [ ] 与文章/贴图同源同事实，不引入未核实信息。
- [ ] （出 mp4 时）`video.mp4` 为 1080×1920、30fps、H.264+AAC；字幕在底部安全区之上且为中文（不是方块）。
- [ ] （出 mp4 时）有旁白的版本音量正常（`ffmpeg -af volumedetect` 的 mean_volume 不应接近 -91dB）；图文轮播可以静音。
