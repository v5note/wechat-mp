# 风格库（style-catalog）

> 从用户提供的 **35 张贴图 + 15 篇文章 + 3 个视频号**素材里提炼出的可复用风格 DNA。
> 选风格不是选颜色，而是选**版面结构 + 图文关系 + 语气**。本文件是「智能选题 → 选风格」的查表依据，
> 所有主题令牌落在 [../assets/tokens.css](../assets/tokens.css)，样张在 [../assets/style-specimens/](../assets/style-specimens/)。

## 0. 三步选风格

1. **判素材档**（[materials](materials.md)）：抽象概念/方法论 → T0 程序化；真实产品/公司 → T1 必须有真截图/logo；需要氛围 → T2 生成图。
2. **判体裁**（[content-playbook](content-playbook.md)）：产品发布 / 项目推荐 / 教程一图流 / 数据复盘 / 横评对比 / 口播视频。
3. **查表选风格**：体裁 × 读者 → 下面「贴图风格库」挑一套主题 + 卡片序列；文章按下「文章风格库」挑骨架。

**默认交付**：2 个版本（深色科技 + 浅色清新）× 2 种格式（贴图套图 + 长文）= 4 个样例。
**进阶交付**：从风格库显式挑 1 套「主题 + 骨架」，做 1 个高完成度样例；需要时再加 1 个视频号产出。

### 通用贴图节奏
封面 1 + 要点 3–7 + 结尾 1 = **5–9 张**；超过 9 张拆两组。
每张只讲一个信息；标题 ≤2 行；每卡一个强调色；安全区四周 ≥64px。

### 新增的卡片骨架（build.mjs 的 `cards[].variant`）
| variant | 用途 | 关键字段 |
|---|---|---|
| `cover` | 封面 | title[2行] / accent / sub / hero / tags / kickerPill |
| `point` | 单点结论 | label / title / body / hero / num |
| `diagram` | 图解 | kicker / title / hero / caption |
| `compare` | 新旧对比 | title / left / right / caption |
| `list` | 要点清单（编号或图标） | kicker / title / items[{t,d,icon,num}] |
| `grid` | 合集/榜单卡片墙 | kicker / title / items[{num,t,desc,fields,tags}] / cols |
| `stat` | 数据大字 | kicker / title / stats[{num,label}] / caption |
| `quote` | 金句大字 | quote / accent / author |
| `ending` | 结尾 CTA | title / points[] / cta / ctaKicker / qr |

### 新增视觉组件（`hero.type`）
`browser`（截图框）/ `code`（代码窗）/ `flow`（流程）/ `steps`（编号步骤）/ `stack`（分层）/
`tiles`（图标簇）/ `ring`（中心辐射）/ `matrix`（字段卡片墙）/ `checklist`（勾选清单）/
`kv`（键值表/技术栈）/ `stats`（数据大字）/ `blist`（要点列表）。

## 2. 文章风格库（6 种骨架）

| 骨架 | 标题范式 | 结构（节） | 语气 | 配图 |
|---|---|---|---|---|
| **A · 开源项目推荐（刘哥式）** | 「开源｜一款……，支持……」「又挖到……：1.4 万 Star」 | 痛点场景 → 它是什么 → 核心能力（01/02…）→ 上手 → 边界提醒 → 写在最后+点赞 | 口语、诚实、讲边界、具体数字 | 封面 + 架构/界面图 + 能力图解 + 对比表 |
| **B · 产品发布** | 「……终于来了」「不用再……了」 | 痛点 → 我们做了什么 → 核心能力 → 怎么用（3 步）→ 价格/协议 → CTA | 有力、利益点前置 | 界面主图 + 功能动线 + 对比 |
| **C · 横评对比** | 「A、B、C 怎么选：……横向对比」 | 结论先行 → 对比维度表 → 逐个点评 → 按场景选 → 边界 | 中立、给判断 | 维度矩阵图 + 评分表 |
| **D · 教程一图流** | 「照着点就行：……四步……」「一张图搞懂……」 | 承诺+效果 → 全流程图 → 分步（每步一图+避坑）→ 总清单 → 风险 | 手把手、给模板 | 一图流总览 + 每步截图 |
| **E · 数据复盘** | 「……只做 X，远远不够」 | 反常识结论 → 指标体系图 → 逐指标（定义/阈值）→ 误判 → 行动清单 | 冷静、结构化 | 指标图 + 趋势图 + 表 |
| **F · 口播视频工作流** | 「我用 X 做口播，3 个 Skill 就够了」 | 痛点 → 工作流全图 → 每步工具/参数 → 成品对比 → 边界 | 亲历、可复制 | 工作流图 + 前后对比 |

**通用硬约束**：正文 ≥800 字（建议 1500–3000），≥3 张配图，「文字介绍 + 图片」交替；小标题结论式且编号统一；
图注固定「图N：一句话」；技术类必写「边界/风险/适用性」；html 全内联。

## 3. 视频号风格库（可选产出 · 3 种）

| 形式 | 时长 | 画面 | 适合 | 产出 |
|---|---|---|---|---|
| **口播干货** | 30–60s | 真人/数字人口播 + 大字幕 + 关键画面 | 观点、工具推荐、避坑 | 口播稿 + 分镜 + 竖版封面 |
| **图文轮播** | 15–40s | 6–9 张竖版卡片轮播（可复用贴图） | 清单、教程、榜单 | 卡片序列 + 转场节奏 + 封面 |
| **屏幕解说** | 45–90s | 录屏 + 旁白 + 局部放大/标注 | 软件演示、操作教学 | 录屏脚本 + 标注点 + 封面 |

规范与字段见 [video-format](video-format.md)；`spec.video` 交给 `scripts/build.mjs` 会生成 `video/cover.png`、`video/口播稿.md`、`video/分镜.md`。

## 5. 智能路由（关键词 → 推荐）

| 输入信号 | 体裁 | 首选贴图风格 | 文章骨架 | 视频 |
|---|---|---|---|---|
| 开源项目 / Star / License / GitHub | 项目推荐 | forest 或 dark | A 项目推荐 | 口播 |
| 新版本 / 上线 / 发布会 | 产品发布 | ocean 或 forest | B 产品发布 | 屏幕解说 |
| 工具 / Skill / 插件 / 效率 | 项目推荐 | aurora 或 sky | A / D | 口播 |
| 教程 / 怎么用 / 步骤 / 一图流 | 教程一图流 | sky 或 cream | D 教程 | 图文轮播 |
| 对比 / 选型 / 哪个好 / 横评 | 横评对比 | mono 或 light | C 横评 | 口播 |
| 数据 / 复盘 / 指标 / 增长 | 数据复盘 | dark 或 cream | E 数据复盘 | 屏幕解说 |
| 榜单 / 合集 / 盘点 / N 个 | 合集 | cyber | D / A | 图文轮播 |
| 设计 / UI / 灵感 / 组件 | 设计干货 | rose 或 midnight | A / D | 图文轮播 |
| 原理 / 架构 / 系统 / 机制 | 原理图解 | cream | D | 屏幕解说 |

**判断顺序**：先看「有没有真实产品/品牌」→ 决定 T1 真素材与 forest/ocean/rose；再看「是不是清单/教程」→ sky/cyber；
最后看读者：开发者偏 dark/forest/cyber，泛读者偏 light/aurora/sky/rose。
