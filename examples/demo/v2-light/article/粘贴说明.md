# 粘贴到微信公众号 · 操作说明

> 由 scripts/build.mjs 自动生成。article.html 是**片段**（只有一个根 <section>），article-preview.html 才是整页预览。

## 一、正文怎么粘

1. 用浏览器打开 **article-preview.html** 核对排版（这是本地预览，不要在这里全选）。
2. 用**文本编辑器**打开 **article.html**，全选复制（Cmd+A / Cmd+C）。
3. 在公众号编辑器正文区 **Cmd+V**；粘贴后先看四件事：段落颜色/字号保留、小标题加粗且为蓝色、图注在、目录框保留。
4. **不要**在浏览器里打开 article.html 再全选复制——浏览器会连整页样式一起打包进剪贴板，粘贴后容易乱。

## 二、图片怎么进

- article.html 里的图片是占位：src 为 images/figN.png（相对路径），微信里一定会裂。
- 粘完文字后，在编辑器里按图注顺序用「图片」按钮上传 article/images/fig1 → fig3，替换对应占位位置。
- 题图/封面不走正文：用 article/cover.png（2.35:1）设封面，分享卡片的 1:1 图用 cover-square.png。

## 三、会被微信清理、已经提前规避的写法

- 整页外壳（doctype / html / head / body / title）：article.html 不输出。
- h1、h2、figure、figcaption、hr、table、blockquote：全部改写成 p/span/strong/img。
- font-family、letter-spacing、max-width、margin auto：从根节点去掉；字体会回到微信默认，这是正常现象。
- <style>、<script>、外链字体：一律不输出。

## 四、粘贴后逐项核对

- [ ] 标题仍是加粗大字；小标题是「一、二、三」编号的蓝色加粗。
- [ ] 图注「图N：…」在图下方、灰色居中。
- [ ] 分割线两侧留白正常（由 1px 空段落实现）。
- [ ] 列表逐条分行，没有被并成一段。
- [ ] 手机预览：无乱码、无裂图、无多余空行。
