# 发布清单 · Atlas 浅色清新版

## 贴图
- [ ] 图片共 7 张，顺序：cover → point → diagram → diagram → point → compare → ending
- [ ] 每张 1080×1440（3:4），PNG；单张 >2MB 时压到 JPG 90
- [ ] 首图 3 秒可懂；标题 ≤20 字：3 分钟看懂一个项目
- [ ] 每卡一个信息、一个强调色、标题 ≤2 行；安全区 ≥64px
- [ ] 配文 ≤100 字 + 一个 CTA；结尾卡含二维码/关键词

## 文章
- [ ] 标题：3 分钟看懂一个陌生项目，Atlas 帮你画出来
- [ ] 摘要 ≤54 字（当前 42 字）
- [ ] 正文 ≥800 字（当前 878 字），含「文字介绍 + 配图」的图文长文
- [ ] 封面：2.35:1（1080×460）与 1:1 方版（1080×1080）各一张；正文配图 3 张（≥3），编号连续
- [ ] 每图有「图N：」图注；段落 ≤4 行
- [ ] article.html 是片段（仅一个根 <section>、只用 p/span/strong/img），不含 doctype/html/head/body 与 h1/h2/figure/hr/table
- [ ] **粘贴方式**：用文本编辑器打开 article.html 全选复制后粘进编辑器；不要在浏览器里全选整页复制。细则见 article/粘贴说明.md
- [ ] **配图要手动上传（必做）**：article.html 里的图片是相对路径 images/figN.png，粘进编辑器后图片会失效；按图注顺序把 3 张配图从 article/images/ 逐张上传并插入（fig1 → fig3）
- [ ] 上传后点「预览」，确认图注「图N：…」与图片一一对应、编号连续
- [ ] 封面：在编辑器里单独选 2.35:1 封面；公众号后台若要求 1:1 分享图，用 cover-square.png
- [ ] 原创声明：勾选「原创」并填作者；正文里不要出现「本文由 XX 生成」这类元信息
- [ ] 手机预览：无乱码、无失效图片

## 发布前再核一遍（最容易被漏的）
- [ ] 贴图按「图片消息」发时配文只有一段：用 文案.md 里的 ≤100 字配文，别贴整篇正文
- [ ] 结尾卡/文末的「下期预告」必须与真实排期一致，不一致就先删掉（不承诺不存在的内容）
- [ ] 文中数字（主题数 / 字数 / 尺寸）与当前版本仓库一致
